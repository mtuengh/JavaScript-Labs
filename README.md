## Nội dung các bài Lab

### Lab 08 – JavaScript 1: Language Foundations

Thực hành các kiến thức nền tảng của JavaScript, bao gồm:

- Nhúng JavaScript vào HTML và sử dụng file JavaScript bên ngoài.
- Sử dụng Chrome Developer Tools để kiểm tra và gỡ lỗi.
- Làm việc với biến, kiểu dữ liệu, toán tử và các đối tượng có sẵn.
- Sử dụng mảng, vòng lặp, hàm và đối tượng JavaScript.
- Xử lý mảng chứa nhiều đối tượng.

**Thư mục mã nguồn:** `Lab08/`

### Lab 09 – JavaScript 2: DOM and Events

Thực hành các kỹ thuật tương tác với trang web thông qua DOM và sự kiện:

- Truy xuất phần tử HTML bằng các phương thức DOM.
- Tạo, thay đổi và xóa phần tử HTML.
- Xử lý các sự kiện chuột và sự kiện tải trang.
- Sử dụng breakpoint trong Chrome Developer Tools.
- Xử lý biểu mẫu và kiểm tra dữ liệu nhập.

**Thư mục mã nguồn:** `Lab09/`
