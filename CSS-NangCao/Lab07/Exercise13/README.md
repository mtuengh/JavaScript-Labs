# Exercise 7.13 – Setting the Viewport

Theo tài liệu hướng dẫn của giảng viên, Exercise 7.13 **tiếp tục chỉnh sửa Exercise 7.12** (không cần một trang HTML riêng).

Mở `../Exercise12/index.html#viewport-demo` để xem kết quả. Nội dung đã thực hiện:
- `<meta name="viewport" content="width=device-width, initial-scale=1">` trong `Exercise12/index.html`.
- Desktop và mobile CSS tách riêng trong `desktop.css` / `mobile.css`, liên kết có điều kiện `media`.
- Menu mobile đóng/mở bằng checkbox CSS, không cần JavaScript.
- Kiểm tra màn hình ~390px và ~1280px bằng Chrome DevTools.
