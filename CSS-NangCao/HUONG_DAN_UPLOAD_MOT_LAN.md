# HƯỚNG DẪN UPLOAD MỘT LẦN

1. Giải nén `CSS_NangCao_HoanChinh.zip` trên máy tính.
2. Mở repository học phần **đang dùng**, ví dụ `https://github.com/mtuengh/JavaScript-Labs`.
3. Chọn nhánh `main` → **Add file** → **Upload files**.
4. Kéo **toàn bộ thư mục `CSS-NangCao`** (không kéo file ZIP) vào trang upload. Chờ GitHub liệt kê các file với đường dẫn `CSS-NangCao/...` rồi chọn **Commit changes**.
5. Trường hợp GitHub không nhận kéo-thả nguyên thư mục: dùng **GitHub Desktop** → File → Add local repository (hoặc Clone repository) → copy thư mục `CSS-NangCao` vào thư mục repo clone → Commit to main → Push origin. Chỉ một lần push, không đụng bài cũ.
6. Vào Settings → Pages → Deploy from a branch → `main` và `/ (root)` nếu chưa bật. Mở `/CSS-NangCao/` theo địa chỉ GitHub Pages.
7. Thay `[Điền họ tên]`, `[Điền MSSV]`, `[Điền lớp học phần]` trong `index.html` và `README.md`, thêm ảnh cá nhân nếu muốn, trước khi upload.
8. Nộp báo cáo Word riêng trên LMS; không cần upload báo cáo Word vào website.

**LƯU Ý:** Nếu trên repo đã có thư mục `CSS-NangCao` từ bộ starter, thao tác này cập nhật các file trùng tên và bổ sung các bài còn thiếu; kiểm tra tên và đường dẫn trước khi commit.
